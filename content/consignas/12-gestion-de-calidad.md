# De la Gestión del Proyecto a la Calidad del Producto y del Servicio: Integración de PMBOK, ISO 25010, ISO 12207, ISO 20000 e ISO 33000

1. Calidad del Producto de Software ISO/IEC 25010

Identificar las características / subcaracterísticas del modelo de Calidad que cumple el Producto a desarrollar

2. Evaluar el comportamiento integral de la operación y gobernanza del servicio según ISO/IEC 20000-1

3. Identificar Procesos de Transición del Software, de Operación del Software y de Mantenimiento del Software según ISO/IEC/IEEE 12207 4. Seleccionar un proceso clave del proyecto y realizar la evaluación según ISO/IEC 33000 en base a:

− Nivel 0 (Incompleto): El proceso no se ejecuta o no logra sus salidas.
− Nivel 1 (Ejecutado): Se logran los resultados esperados de forma reactiva/artesanal.
− Nivel 2 (Gestionado): Se planifica, monitorea y ajusta; los entregables están controlados.
− Nivel 3 (Establecido): Se utiliza un proceso estándar definido a nivel organizacional.
− Nivel 4 (Predecible): Se opera con límites de control cuantitativos y estadísticos.
− Nivel 5 (En optimización): Se mejora continuamente en base a análisis cuantitativo de causas comunes de variación.
