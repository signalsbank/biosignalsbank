# Gestión de las Comunicaciones

Incorporar al proyecto la planificación de las comunicaciones internas y externas.

El objetivo de esta actividad es identificar qué información necesita comunicarse durante el proyecto, quién es responsable de comunicarla, a quién debe comunicarse, mediante qué medio y en qué momento o con qué frecuencia.

1. Comunicaciones internas: Identificar las principales comunicaciones que se producen dentro del equipo de proyecto. Ejemplo:

| ¿Qué se comunica?                          | ¿Quién comunica?          | ¿A quién/es comunica? | ¿Cómo se comunica?            | ¿Cuándo? / Frecuencia          |
| ------------------------------------------ | ------------------------- | --------------------- | ----------------------------- | ------------------------------ |
| Asignación de tareas                       | Líder del proyecto        | Equipo de desarrollo  | Canal \#proyecto de Discord   | Al inicio de cada iteración    |
| Avance de tareas                           | Integrantes del equipo    | Equipo completo       | Reunión + Discord             | Semanalmente                   |
| Cambios en los requisitos                  | Responsable de requisitos | Equipo completo       | Canal \#requisitos de Discord | Cuando se aprueba un cambio    |
| Problemas o bloqueos                       | Integrante afectado       | Líder / equipo        | Grupo de WhatsApp             | Cuando se presenta el problema |
| Entrega de una funcionalidad para revisión | Desarrollador responsable | Líder / equipo        | GitHub + canal de Discord     | Al finalizar la tarea          |

Importante: se debe indicar específicamente la herramienta y el espacio utilizado. Por ejemplo, no colocar solamente "Discord", sino "Canal \#desarrollo de Discord"; no solamente "WhatsApp", sino "Grupo de WhatsApp del equipo BBVA".

2. Evidencias de las comunicaciones internas: Además de definir cómo se realizarán las comunicaciones, deberán incorporar evidencias del uso real de al menos algunos de los medios definidos durante el desarrollo del proyecto. Por ejemplo: captura de una reunión del equipo, conversación donde se coordinaron tareas, utilización de un canal de Discord, asignación o discusión de una actividad mediante GitHub, etc. No se busca mostrar conversaciones personales, sino evidenciar que los canales definidos están siendo utilizados para organizar y gestionar el proyecto.

3. Comunicaciones externas: Identificar las comunicaciones que se realizan entre el equipo del proyecto y personas u organizaciones externas al equipo, particularmente clientes, usuarios, referentes, docentes, especialistas u otros interesados. Para cada comunicación se deberá indicar nuevamente qué se comunica, quién lo comunica, a quién, por qué medio y cuándo o con qué frecuencia. Ejemplo:

| ¿Qué se comunica                               | ¿Quién comunica?              | A quién/es comunica?          | ¿Cómo se comunica?             | ¿Cuándo? / Frecuencia                   |
| ---------------------------------------------- | ----------------------------- | ----------------------------- | ------------------------------ | --------------------------------------- |
| Relevamiento de necesidades                    | Analista / Líder del proyecto | Responsable de la clínica     | Reunión presencial/Meet        | Al inicio y cuando sea necesario        |
| Validación de requisitos                       | Líder del proyecto            | Cliente                       | Reunión + documento compartido | Al finalizar el relevamiento            |
| Presentación de avances                        | Equipo del proyecto           | Cliente                       | Google Meet                    | Cada 15 días                            |
| Consulta sobre disponibilidad de profesionales | Analista                      | Personal administrativo       | WhatsApp / Email               | Según necesidad                         |
| Solicitud de aprobación de un cambio           | Líder del proyecto            | Cliente                       | Email                          | Cuando se solicita un cambio de alcance |
| Entrega de una versión para validación         | Líder del proyecto            | Cliente y usuarios referentes | Reunión / sistema desplegado   | Al finalizar una versión                |

4. Evidencias de las comunicaciones externas: Al igual que en las comunicaciones internas, deberán incorporarse evidencias de las comunicaciones externas que efectivamente hayan realizado, cuando corresponda: reuniones con el cliente, consultas, validaciones, presentación de prototipos, intercambio de documentación, etc.
